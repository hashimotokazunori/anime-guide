# アニメの窓口（公開用）

このフォルダの中身をそのまま公開すると、サイトとして動きます。

| ファイル | 中身 |
|---|---|
| `index.html` | サイト本体 |
| `config.js` | 楽天アフィリエイトのID・機能のオン/オフ |
| `extras.js` | 公式YouTube予告編の埋め込み、楽天の商品画像 |
| `trailers.json` | 作品名 → 公式YouTube動画ID |
| `now.json` | 今期の配信DB（`update_now.py` で更新） |
| `titles.json` | シーズン別 全アニメのタイトル一覧 |

## 1. GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例: `anime-guide`、Public）。
2. このフォルダの中身を全部アップロードする（「Add file」→「Upload files」）。
3. リポジトリの「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存。
4. 数分後に `https://<ユーザー名>.github.io/anime-guide/` で見られるようになる。

`index.html` をパソコンでダブルクリックして開くと、`now.json` などが読み込めず一部が動きません。
手元で確かめるときは、このフォルダで `python -m http.server 8000` を実行し、`http://localhost:8000` を開いてください。

## 2. 公式YouTube予告編

- 作品の詳細を開くと「公式PVを再生」ボタンが出ます。押したときに初めてYouTubeを読み込みます（プライバシー強化モード `youtube-nocookie.com`）。
- 動画は各作品の公式チャンネル（制作会社・配給会社・アニメ公式）が上げたものだけを使っています。
- 差し替えたいときは `trailers.json` の動画IDを書き換えてください。動画IDはYouTubeのURL `watch?v=` の後ろの11文字です。
- 公式の動画が削除・非公開になると再生できなくなります。たまに確認してください。

### 予告編を自動で集める（YouTube Data API）

親フォルダの `fetch_trailers.py` で、作品名から公式チャンネルのPVを探して `trailers.json` に足せます。

1. Google Cloud で「YouTube Data API v3」を有効にし、APIキーを作る（無料）。
2. キーを環境変数に入れて実行する。

```
$env:YOUTUBE_API_KEY = "取得したキー"
python fetch_trailers.py --seasons 2026-10 2026-07
```

- 採用するのは、公式とみなせるチャンネル（製作・配給会社、テレビ局、作品公式）が上げた、埋め込み可能な動画だけです。
- 無料枠は1日10,000ユニットで、1作品あたり約100ユニット使うので、1日に探せるのは90作品くらいです。
- `--all` を付けると全作品を新しい順に探します。毎日実行すると続きから進みます（見つからなかった作品は30日間は探し直しません）。
- 追加された動画は `trailers_review.csv` に一覧で出ます。違う動画が入っていたら `trailers.json` から消してください。
- 画像は「おすすめ」のポスター、「今期の配信DB」と「全アニメ一覧」の小さなサムネイルに使われます。

## 3. 楽天アフィリエイト（商品画像）

1. 楽天アフィリエイトに登録し、アフィリエイトIDを確認する。
2. 楽天ウェブサービス（https://webservice.rakuten.co.jp/）でアプリIDを発行する。「アプリURL」には公開したサイトのURLを入れる。
3. `config.js` の `applicationId` と `affiliateId` に入れて、アップロードし直す。

入れると次のようになります。
- 作品の詳細に、楽天ブックスのBlu-ray・DVDの商品画像とリンクが出る（「PR」表記つき）。
- おすすめ24作品のポスターが、パッケージ画像に置き換わる（不要なら `posters: false`）。

守ること:
- **「PR」表記を消さない。** 広告であることを示す表示は法律（景品表示法のステルスマーケティング規制）で必要です。
- **「Supported by Rakuten Developers」の表記を消さない。** 楽天ウェブサービスの利用規約で求められています。
- 商品画像は、APIから返ってきたURLのまま表示する。保存して載せ直さない。
- 楽天のAPIは1秒に1回までなので、サイト側で間隔を空けて呼び、結果を24時間ブラウザに保存しています。
- 楽天側でAPIのURLや仕様が変わった場合は、`config.js` の `endpoint` を楽天ウェブサービスの最新の案内に合わせて直してください。

### コナン相関図の人物画像（楽天の商品画像）

相関図の各人物のカードに、楽天市場で販売中の関連グッズの画像を出せます。

```
$env:RAKUTEN_APP_ID = "楽天のアプリID"
$env:RAKUTEN_AFFILIATE_ID = "楽天のアフィリエイトID"
python fetch_conan_goods.py
```

- 人物ごとに「缶バッジ → アクリルスタンド → フィギュア → グッズ」の順で探し、商品名にその人物の名前が入っているものを使います。結果は `site/conan/conan-goods.json` に保存されます。
- 見つからなかった人物は `goods_missing.txt` に出ます。相関図では、同じ大きさの枠に勢力のマークが出ます。
- 自分で選んだ商品にしたい人物は、`conan-goods-manual.json` に書くと自動検索より優先されます。
- 在庫は入れ替わるので、週に1回くらい実行し直してください。特定の人物だけなら `python fetch_conan_goods.py amuro kid` のように指定できます。
- 画像は切り抜かずに表示し、押すと楽天の商品ページが開きます。「PR」表記も自動で付きます。

## 4. 配信サービスのアフィリエイト

1. A8.net・もしもアフィリエイト・バリューコマースなどのASPに登録する（サイトを公開してから申し込む）。
2. 各配信サービスの広告プログラムに提携を申し込む。U-NEXT・DMM TV・dアニメストア・ABEMA・Hulu などに広告プログラムがあります（Netflix のように広告プログラムが無いサービスもあります）。
3. 提携が承認されたら、ASPの管理画面で「テキストリンク」の広告URLを発行し、`config.js` の `affiliate.services` の該当サービスに入れる。

入れたサービスは、配信DBの「●」と、作品詳細のサービス名がそのサービスへのリンクになります。

## 5. Google AdSense（広告）

1. サイトを公開し、`privacy.html` の黄色い部分（制定日・運営者名・お問い合わせ先）を書き換える。お問い合わせ先が無いと審査に通りにくくなります。
2. https://adsense.google.com/ で申し込み、サイトのURLを登録する。審査には数日〜数週間かかります。
3. 審査中に求められたら、`ads.txt` の `pub-0000000000000000` を自分のIDに書き換え、先頭の `#` を外す。
4. 承認されたら、AdSense の「広告」→「広告ユニットごと」でディスプレイ広告を作り、`config.js` の `ads` にパブリッシャーID（`ca-pub-…`）と広告ユニットのIDを入れる。

広告が出る場所は4か所です。使わない場所は空欄のままにしてください。
- `top`：タブのすぐ下
- `list`：おすすめ一覧の途中（`listEvery` 作品ごと）
- `dialog`：作品詳細の一番下
- `footer`：ページ下部

GitHub Pages の `https://<ユーザー名>.github.io/anime-guide/` のようなサブフォルダのURLでは、`ads.txt` がサイトの一番上に置けないため、AdSense に申し込めない場合があります。その場合は独自ドメインを取って GitHub Pages に設定してください。

## 広告・アフィリエイトで守ること

- **PR表記**：広告やアフィリエイトを1つでも入れると、ページ上部に「当サイトはアフィリエイト広告を利用しています」と自動で出ます。消さないでください（景品表示法のステルスマーケティング規制）。
- **広告リンクの印**：広告リンクには `rel="sponsored"` が自動で付きます。
- **自分でクリックしない**：自分の広告を自分でクリックすると、AdSense やASPの規約違反でアカウントが停止されることがあります。
- **画像の扱い**：アフィリエイトの商品画像は、各ASPやAPIから提供されたものをそのまま使ってください。他サイトの画像を保存して載せ直すのは規約違反・著作権侵害になります。

## 6. 配信DBの毎月の更新

親フォルダの `update_now.py` を使います。

```
python update_now.py --seasons 2026-10 2026-07
```

- dアニメストアとDMM TVは自動で判定されます。
- それ以外のサービスと、自動判定で期を特定できなかった作品は `manual_check.csv` に出るので、JustWatchのリンクから確認して `now.json` を直します。
- 変更点は `changes_日付.md` にまとまります。
- 新しいクールが始まったら `--seasons 2027-01 2026-10 --refresh-titles` のように、新しいシーズンを足してタイトル一覧も取り直します。
- できた `now.json` をこのフォルダにコピーして、アップロードし直してください。
